Detection principles

Bandingkan periode yang sepadan, kendalikan hari dalam minggu dan pola musiman, lalu periksa page views, RPM, matched requests, negara, dan perangkat. Threshold hanya pemicu investigasi. CTR tinggi atau perubahan trafik sendiri bukan bukti invalid traffic.

Production checklist

  • Backend API dengan HTTPS dan autentikasi admin.
  • Dua OAuth authorization flow / credential set yang terpisah.
  • AdSense Management API v2, GA4 Data API, Search Console API diaktifkan.
  • PostgreSQL untuk menyimpan snapshot historis.
  • Scheduler, retries, logs, dan alerting untuk sync failure.

Deployment notes

GitHub Pages bisa menyajikan UI statis, tetapi tidak dapat menyimpan secret, menjalankan scheduler backend, atau menyediakan database privat. Integrasi produksi membutuhkan backend terpisah (mis. FastAPI di server/container platform) dan database. Frontend ini sekarang hanya demo dan tidak mengambil data aktual Google.

Contoh nama environment secrets: GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, ADSENSE_ACCOUNT_1_REFRESH_TOKEN, ADSENSE_ACCOUNT_2_REFRESH_TOKEN, DATABASE_URL, APP_SESSION_SECRET.
